Classroom lesson plan

Automate your own project.

Six 20-minute lessons turn one trustworthy-automation principle into something you can build in a free GitHub account. A seventh exercise is an optional stretch.

How to read the labels

VERIFIED

Read in the cited file, commit, receipt, or workflow.

INFERRED

A synthesis drawn from evidence, not a directly stored fact.

REPORTED

Stated in a lane report, without a public artifact to inspect here.

Bring one small repository

Before you start

You need a free GitHub account, one repository you can change, and one GitHub Actions workflow. The project can be a tiny class assignment, a personal site, or a blank practice repo.

Six lessons, plus one stretch

Each card connects a principle to a real Xpired artifact, then gives you one small guardrail to build and one matching ground truth to study.

LESSON01

Write the brief before the code

VERIFIED

PrincipleAutomation starts as a one-page contract: scope, the proving command, and what must not happen.

Xpired exampleThe lane brief fixes the facts, deliverables, decisive command, one mutation that must fail, and the prohibitions in es-ops/briefs/20260901-B0-kpi-truth-and-dead-plists.md.

20-minute exerciseWrite a half-page brief for one chore in your project. End with the exact shell command that proves it is done. Trade briefs with a partner and ask them to run the command without extra instructions.

First ground truth to buildGT7: Let the runner write the receipt
LESSON02

A checklist is not a gate

VERIFIED

PrincipleIf a person must remember a check, it will eventually be skipped. Put the check in the path of the change.

Xpired exampleOn August 8, 2026, two submission preconditions were wrong while a readable checklist still existed. ios_apps/fastlane/asc/asc_presubmit_check.py became the executable gate; private product repository commit eb555954 records the related live-listing correction.

20-minute exerciseChoose one “before you submit” sentence from your README. Turn it into a GitHub Actions step that fails the pull request when the condition is false. Break the condition and confirm a red run.

First ground truth to buildGT2: Probe the outside world
LESSON03

Read back every write

VERIFIED

PrincipleThe test of a change is the second call, not the first call’s exit code.

Xpired exampleios_apps/fastlane/asc/asc_reconcile.py reads the version and build again after every change and returns stable failure codes. The August 8, 2026 drift incident is recorded in private product repository commit eb555954.

20-minute exerciseCreate a GitHub issue through the API. Write a script that fetches it again and fails unless the body matches. Edit the issue by hand, run the script again, and watch it catch the drift.

First ground truth to buildGT1: Read back every write
LESSON04

Gate on counts, not vibes

VERIFIED

PrincipleA checker that can silently find nothing is worse than no checker.

Xpired example.github/workflows/release-contracts.yml derives test totals from collection and refuses success below its recorded MINIMUM_GATED_FILES floor, which rises as tests are added. The file records the bad pattern that found zero paths and could have produced a green check.

20-minute exerciseAdd a workflow step that counts the test files in your repo and fails below today’s number. Delete one test file on a practice branch and confirm that the workflow refuses the change.

First ground truth to buildGT4: Derive test counts from collection
LESSON05

Stamp identity into what you ship

VERIFIED

PrincipleIf you cannot prove which bytes are live, you cannot audit a bug report or choose the right rollback.

Xpired examplebackend/Dockerfile adds the release commit to the image, and .github/workflows/fly-deploy.yml promotes the same immutable digest that passed the canary check.

20-minute exerciseAdd a /version endpoint or footer that prints git rev-parse HEAD at build time. Publish two GitHub Pages revisions or run two local builds and confirm that the value changes.

First ground truth to buildGT6: Hash source identity into the artifact
LESSON06

Make consent and deletion real

VERIFIED

PrincipleA “yes” is perishable. Re-check it at the moment of use, and make “no” remove the data.

Xpired examplebackend/server/services/training_consent.py uses a live-consent lease and a tombstone. Private product repository commit 3be85e17 fixed the September 1, 2026 cached echo defect, and 37 pinned tests fence the withdrawal path.

20-minute exerciseIn a toy mailing list, make unsubscribe delete the row. Write a test that signs up, unsubscribes, and then asserts that the query returns zero rows.

First ground truth to buildGT8: Read consent back before data moves
STRETCH07

Let public claims cite their proof

OPTIONAL

PrincipleEvery public claim gets a pointer to evidence, and the workflow checks that the pointer still works.

Xpired examplebackend/server/tests/test_appstore_claim_ledger.py binds store copy to source anchors. tests/product-truth.test.js refuses new website copy by default.

20-minute exerciseWrite one truthful claim about your project and link it to the test that proves it. Add a workflow step that fails when the test file is renamed, then rename it on purpose.

First ground truth to buildGT9: Bind every product claim to source

Capstone message

INFERRED

You do not need a large team to start. A free GitHub account, one Actions workflow, and the habit of writing the proving command first reproduce the skeleton of the system Xpired uses to run a product, a careful model pipeline, and an internship program.
