What is actually true today

Read this before you write a line of code. Every line below is checked against the running system, not against a slide. Probed 2026-08-16.

No ML model ships in the app. There is no .mlmodel bundled in the iOS app, and the production backend reports every ML flag false: custom_model_available, ood_evaluator_loaded, yolo_loaded, and produce_crop_classifier_loaded are all false on /health right now.
The scanner is compile-time off. AppConfiguration.swift gates scannerEnabled behind #if DEBUG && SCANNER_LAB, so a normal build cannot reach it. Any page, doc, or README that describes a working freshness scanner is describing a target, not a shipped feature.
The only shipping AI feature is fridge photo enumeration. POST /api/v1/fridge/enumerate sends the photo to a vision provider and gets back a list of items. It identifies what is in the fridge. It does not score freshness, and it has never been scored itself. Producing that first score is a Week 10 seat.
App Store submission is OFF. It stays off until the scanner clears an in-store gold set. The gold gate fails 5 of its 6 floors today, so no candidate is promotable and nothing is submitted.
Interns build the maintenance automations. Interns do not touch production. Neither Week 10 intern has, or should get, write access to the product repository. Every seat is propose-only: it opens a pull request or writes a digest, and a human applies it. No seat merges, deploys, or holds a production credential.

The five steps, in order

  1. Get the code, then activate the virtual environment. PR #248 is not merged, so the agents are not on main. Check the pull request branch out at its exact head: gh pr checkout 248 --repo LawrenceHua/es-intern-freshlens git rev-parse HEAD # expect 41ef4b86e2379e444518e043a9d99a4e55d3014e source venv/bin/activate
  2. Run the one lane that is expected to pass. python scripts/maintainer_agents/claims_routing.py --once # expect VERIFIED, exit 0 The other two lanes return BLOCKED and exit 1 by design. That is an honest outcome, not a failure to fix: python scripts/maintainer_agents/dedup_inventory.py --once # expect BLOCKED, exit 1 python scripts/maintainer_agents/ground_truth_data.py --once # expect BLOCKED, exit 1
  3. Read the evidence, do not trust the exit code alone. Each iteration prints one sorted JSON line with lane, iteration_id, measurement_status, status, proposal, stop_reason, last_clean_verified_error, containment_status, and containment_error. Then read the append-only record: artifacts/releases/maintainer-agents/runtime/<lane>/observations.jsonl
  4. Do the proposal drill once, supervised. Edit only tracked paths inside that lane's proposal_paths, leave the index and the untracked set clean, then: git diff --binary --no-ext-diff HEAD -- <proposal paths> | shasum -a 256 python scripts/maintainer_agents/claims_routing.py --once --dirty-proof-sha256 <digest> Inspect the proposal it writes, restore the source, and re-run the gate clean. The digest must match exactly, and this option is rejected in unattended operation.
  5. Never drop --once. Omitting it starts an unattended loop at the lane's cadence, which is the mode that is blocked. --containerized, --interval-seconds, --dirty-proof-sha256, and --runtime-root all raise ValueError unless --once is also set. Running scripts/maintainer_agent.py directly is refused on purpose.
Kill switch, one command, stops every seat at once: touch ~/.openclaw/flags/STOP_ES.flag It is checked at the top of every iteration and again before config load. Present means stop_reason: "kill_switch_present", exit 0, and zero filesystem mutation. A probe error is also a stop, because the switch fails closed. Remove the file to resume.
