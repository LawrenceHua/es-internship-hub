The automation inventory

Each automation has a status, a job, and a boundary. The boundary is as important as the job.

Backend schedulers

Flags name capabilities, not their current runtime state. Where a health surface exists, it is the source for a current readback.

The enabling predicate is deliberately narrow.

scheduler_flag_enabled() accepts only the literal string "true"; every flag defaults off and nothing in the repository turns one on.
