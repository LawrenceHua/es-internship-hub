A day of a change

A small request travels through a deliberately visible chain. Each handoff leaves behind something the next person can inspect.

VERIFIED

Eleven stations, eleven artifacts

This sequence is drawn from the system record. File paths name the artifacts, not a promise that a reader can access private operational materials.

01

An owner sentence

A person states what they want in plain language.

briefs/es/20260902-ED1-kimi-system-education.md
02

A queue entry

The planner records the request in the shared mailbox and names the proving rule.

es-ops/briefs/QUEUE.md
03

A bounded brief

The brief fixes scope, proof, and what must not happen.

20260901-B0-kpi-truth-and-dead-plists.md
04

An agent lane

A launcher starts one bounded job and produces local tracking files.

.pid and .launch.log
05

A claim ledger

The lane writes its decisive command output and labels every claim.

reports/<TAG>.md
06

Independent verification

The planner reruns the decisive command, then a fresh reviewer challenges the claims.

es-ops/briefs/QUEUE.md reviewer verdict record
07

Pull request gates

Required checks assess the target branch before a change can advance.

.github/workflows/release-contracts.yml
08

A reviewed merge

A reviewer verdict and a planner rerun are recorded before the branch moves.

es-ops/briefs/QUEUE.md: merge SHA + ci-verify result
09

Release readiness

A human may dispatch a protected release workflow only when it is due.

.github/workflows/shopper-release.yml
10

An external verdict watch

A watcher polls the review state and writes the current observed result.

state/es-asc-verdict-latest.json
11

The release desk

The planner-maintained desk closes the loop with the owner.

state/xpired-release-desk.html

Notice that the arrows do not carry only a request: each one carries an artifact that a skeptic can re-check.

INFERRED

The teaching point

Every handoff produces an artifact a skeptic can re-check: the brief, the report, the claim ledger, the workflow run, or the receipt. This is a paper trail written partly by machines.
